- This directly makes a Spotify playlist consisting of songs that sound similar to any songs that you choose.

- Flask backend, React frontend, KNN algorithm for recommendations, Spotipy for generating playlists, and a dataset of 30K songs to choose from.

- To run on local, download this repo.

- Then make a `.env` file consisting of `CLIENT_USERNAME`, `CLIENT_ID`, `CLIENT_SECRET`. Go to Spotify Developer options, make an account, and you'll get these.

- Then create 2 terminals — one for backend and one for frontend. Run `npm start` on the backend and `npm run dev` on the frontend.
