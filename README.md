this directly makes a spotify playlist consisting of songs that sound similar to any songs that you choose.
flask backend, react frontend, KNN algo for recommendations, spotipy for generating playlists and a dataset of 30K songs to choose from.
to run on local, download this repo.
the make a .env file consisting of CLIENT_USERNAME, CLIENT_ID, CLIENT_SECRET.
go to spotify developer options, make an account and you'll get these.
then create 2 terminals, one for backend and one for frontend.
run npm start on the backend and npm run dev on frontend.
